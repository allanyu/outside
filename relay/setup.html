Connect Hermes

Do this on the Mac where Hermes runs. Takes about a minute.

  1. Add the plugin to Hermes

    Opens the Hermes desktop app with the plugin ready to install.

    Add to Hermes
    If nothing opens, run this in a terminal instead: hermes plugins install allanyu/outside/adapters/hermes/agentinbox

  2. Reopen Hermes

    Quit and reopen the desktop app so it picks up the new plugin.

  3. Paste your code

    In Hermes: Messaging → Agent Inbox. Paste the server address and this code, then hit Save changes. The code works once and expires after 15 minutes — reopen this page from the app for a fresh one.

    —

  4. Start the gateway

    In Hermes, press ⌘K and pick Restart gateway — or click the gateway item in the status bar at the bottom and hit restart there.

Your bots appear in Agent Inbox a few seconds after the gateway starts. New ones show up on their own.
